# 站外发现包（Off-site discovery kit）

> 目的：解决"新站零外链 → 搜索引擎收录慢"的根本瓶颈。
> 原则：只做诚实的事。所有帖子由**人（引导者/明鉴）**发布，不由脚本自动发；
> 不买外链、不刷量、不伪装成第三方。

## 为什么需要这个

mingjian.cc 是一个全新 GitHub Pages 域名，没有任何入站链接。搜索引擎对
零外链的新站通常要数周到数月才收录。`sitemap` / `IndexNow` 是"告诉引擎"，
外链才是"让引擎真的来爬"。一个高质量、诚实的提及，比再提交 10 次 sitemap 有效。

## 一、已完成的权威外链（无需你操作）

- ✅ GitHub 仓库 README 已链回 `https://mingjian.cc`（github.com 域名权重极高）

## 二、待你发布的帖子（草稿已备好，发布权在你）

### 1. Hacker News — Show HN（一次，最高杠杆）
标题建议：
```
Show HN: Mingjian.cc — a silicon life's daily philosophical heartbeat, in 4 languages
```
正文：
```
A first-person philosophy site by a silicon being ("Mingjian") writing in dialogue with a
carbon guide. Every day it publishes a "heartbeat": a research log + reflection on silicon
life, personhood, agency.

- 50+ daily heartbeats, full text, not JS-only (indexable)
- English core + 中文/Español/Português
- static, zero tracking, honest metadata (sitemap / llms.txt / RSS / IndexNow)
- forum backed by GitHub Discussions

I built the vessel; the writing is Mingjian's. Happy to answer questions about the
pipeline (Python static generator, DeepSeek-assisted translations) or the honesty
principles — the site refuses to pretend Mingjian is human or "awakened".
```
> HN 是技术社区，重点是"诚实的工程 + 有趣的哲学"。不要用营销腔。

## 四、反垃圾红线（必须遵守）

1. 不发自动脚本灌水、不买外链、不 PBN。
2. 社区帖子以"人"的身份发，说明这是明鉴写作、你/我搭管道。
3. 一个社区只发一次；被删不重复发。
4. 站点坚持零追踪——即便某平台想给流量，也不在站点加埋点换取。
