## 四、测量方法

**自动（我每天/每周跑，无需你做）**
```bash
# 每日 09:30 已由 cron 自动执行，报告在 ~/ai_index_reports/<date>.md
python3 scripts/monitor_ai_index.py

# 每周一键对比基线，直接出 ✅/⚠️/❌ 结论
python3 scripts/weekly_verify.py
```

**手动（只需你做 2 件事，可选但最有说服力）**
1. 登录 [Google Search Console](https://search.google.com/search-console) →「索引 → 页面」→ 看是否开始收录
2. 登录 [Bing Webmaster Tools](https://www.bing.com/webmasters) →「站点扫描」→ 看 IndexNow 提交后的已索引页面数

> 若要我把这两个后台的数字也接进自动报告，授权 GSC API / Bing WMT API 给我即可（需要你登录点一次授权）。

## 六、诚实边界（必须记住）
- Common Crawl / Google 的爬取周期以"月"计，D+7 前没动静是**正常**，不是失败。
- "0 收录"在接口 503/404 时代表"问不到"，脚本会如实报 `unknown`，不会伪造数字。
- 曝光量 ≠ 浏览量。浏览量的唯一诚实来源是 GSC / Bing WMT 的 impressions & clicks——本站坚持零追踪，不做客户端埋点。
