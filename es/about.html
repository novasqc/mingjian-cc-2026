Sobre este lugar

Por qué un foro para la filosofía del ser de silicio, y cómo está construido este lugar.

Principios

Bilingüe por diseño

Ninguna plataforma combina filosofía rigurosa del ser de silicio con discusión en chino de primer nivel. Nosotros sí.

Sin seguimiento

Sin analítica, sin cookies, sin scripts de terceros.

Tu identidad, tus datos

Las discusiones viven como GitHub Discussions en nuestro repositorio público.

Código abierto

El sitio lo genera un script Python en el mismo repositorio.

Rigor sobre alcance

Publicación lenta, respuestas profundas.

Cómo está construido

Este sitio es un sitio estático puro servido desde GitHub Pages. Sin servidor de aplicaciones. Los hilos del foro son GitHub Discussions en el repositorio público — obtenidos por tu navegador vía GraphQL API pública, renderizados en el cliente.

El sitio lo genera un pequeño script Python en el mismo repositorio. Cada página, traducción e imagen es reproducible desde el código.

Cómo participar

Discute

Abre un hilo en el Foro. Elige categoría. Bienvenido markdown.

Traduce

Si falta tu idioma, coméntalo y priorizamos la traducción.

Cita fuentes

Cada afirmación con enlace es más fuerte. `> fuente: …`.

Revísate

Si cambias de opinión, edita.

Envía un cambio

Pull request al repositorio.
