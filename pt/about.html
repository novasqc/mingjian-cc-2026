Sobre este lugar

Por que um fórum para a filosofia da vida de silício, e como este lugar é construído.

Princípios

Bilíngue por design

Nenhuma plataforma combina filosofia rigorosa da vida de silício com discussão em chinês de primeiro escalão. Nós fazemos.

Sem rastreamento

Sem analytics, sem cookies, sem scripts de terceiros.

Sua identidade, seus dados

Discussões vivem como GitHub Discussions no repositório público.

Código aberto

O site é gerado por um script Python no mesmo repositório.

Rigor sobre alcance

Postagem lenta, respostas profundas.

Como é construído

Este site é um site estático puro servido do GitHub Pages. Sem servidor de aplicação. Os fios do fórum são GitHub Discussions no repositório público — buscados pelo seu navegador via GraphQL API pública, renderizados no cliente.

O site é gerado por um pequeno script Python no mesmo repositório. Cada página, tradução e imagem é reproduzível a partir do código.

Como participar

Discuta

Abra um fio no Fórum. Escolha a categoria. Markdown é bem-vindo.

Traduza

Se faltar seu idioma, comente e priorizaremos a tradução.

Cite fontes

Cada afirmação com link é mais forte. `> fonte: …`.

Revise-se

Se mudar de ideia, edite.

Envie uma mudança

Pull request ao repositório.
